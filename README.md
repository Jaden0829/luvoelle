# Luvoelle

[![Source Available](https://img.shields.io/badge/source-available-2f6feb)](https://github.com/Jaden0829/luvoelle)

Luvoelle 是一个面向 Windows 与 Apple 芯片 Mac 的截图理解与标注桌面应用。它把“截图、取字、翻译、图片标注、视觉拆解、提示词编辑和参考生成”压缩成一条不离开当前应用的工作流。

## 已实现

- `F1`：菜单保真截图标注；在截图层取得焦点前冻结画面，适合右键菜单、下拉框和悬停提示；
- `Alt + S`：全局截图翻译；
- `Alt + O`：全局截图取字，识别完成后自动复制；
- `Alt + T`：打开文本翻译；
- `Alt + P`：截图转结构化生图提示词；
- `Alt + A`：速度优先进入截图层，框选后直接原地标注；
- 所有全局快捷键都可在“设置 → 全局快捷键”中按个人习惯重新录制；重复按键会即时提示，被系统或其他程序占用时不会覆盖原有可用配置；
- Luvoelle 采用托盘优先运行：开机启动或带 `--background` 启动时只在后台预热并监听快捷键，不弹出工作台；主动点击程序图标、双击托盘图标或选择托盘“打开 Luvoelle”才显示工作台；
- 全屏暗色蒙层、放大镜、像素尺寸提示和鼠标框选；
- PP-OCRv6 small 英文、简体中文与常见符号本地离线 OCR，小字与低置信结果自动二次增强；
- OCR 行坐标、置信度与识别框预览；
- OCR 原文点击即可修改；编辑状态才显示取消/保存，保存后自动更新历史，截图翻译会基于修正原文重新翻译；
- 鼠标附近结果浮窗、固定、复制和回到工作台；
- PNG、JPG、WebP 图片导入、拖放与剪贴板粘贴；
- Google 公共翻译端点与 OpenAI 兼容接口；
- Windows 系统加密与 macOS 钥匙串安全存储 API Key；
- 本地文字历史记录，默认不保存截图；
- 托盘常驻和开机启动选项；
- Windows 托盘使用包含多种小尺寸的原生 ICO，在不同任务栏 DPI 下保持可见；
- 多显示器截图窗口与 DPI 缩放适配。
- Apple 芯片 Mac 使用系统屏幕捕获、Retina 原始像素截图、屏幕录制权限引导与 CoreGraphics 窗口吸附；截图层待机时完全隐藏，避免被 ScreenCaptureKit 截入画面；
- 截图蒙层启动预热与复用，并关闭透明后台层的 Chromium 节流；截图状态下支持窗口级和系统级 `Esc` 立即退出。
- 鼠标所在显示器会在截图蒙层取得焦点前通过 Win32 GDI 无损冻结，因此任务栏隐藏图标、右键菜单、下拉框和 Tooltip 等失焦即关闭的临时界面仍会保留；活动屏幕先显示，副屏随后补齐；
- 框选完成后默认复制截图，并对 Windows 剪贴板临时占用执行写入校验和短间隔重试。纯 OCR 模式会在识别完成后让剪贴板同时包含图片与文字格式；
- 截图翻译会先分析 OCR 文字：纯中文自动跳过翻译并缩成紧凑取字浮窗；检测到英文或中英混合时才展开译文；
- 识别结果浮窗支持 `Esc` 关闭；正在修改 OCR 原文时，第一次 `Esc` 只撤销本次修改并退出编辑，再按一次才关闭浮窗；
- 结果浮窗右上角提供阅读尺寸按钮：第一次适度放大，第二次最大化，第三次恢复适度大小，之后在最大化与适度大小之间循环；
- 结果浮窗左下角提供“复制截图”，无需进入编辑器即可把原截图重新写回剪贴板；状态区会实时显示“截图已复制 / 原文已复制 / 译文已复制”；
- 翻译结果浮窗的原文与译文支持独立折叠；点击整条标题栏即可折叠，另一侧自动占满释放的阅读空间，且两侧不会同时折叠；
- 截图识别后或通过 `Alt + A` 可直接进入独立图片编辑器，支持矩形、椭圆、箭头、画笔、文字、Emoji、马赛克、颜色与线宽、撤销/重做、复制和保存 PNG；Emoji 支持常用表情快捷选择、粘贴任意表情、点击放置、拖动、调节大小和删除；马赛克默认使用方形拖拽框选，也可切换圆形拖拽框选或自由笔刷，并调整模糊度；
- 方形和圆形马赛克在拖动及完成后显示淡色虚线选区；完成后继续调整模糊度会实时更新已选区域，辅助线不会进入复制或保存的图片；
- 矩形、椭圆和箭头完成后保持可调状态，但不再叠加蓝色虚线选框；画布直接呈现最终效果，继续调整线宽或颜色仍会实时修改已画标注；
- 结果浮窗不再重复显示底部“复制译文”主按钮；原文与译文各自保留就地复制，翻译失败时译文区会提供“重试”；
- `0.12` 视觉拆解：在独立结果窗中分析商品、材质、色彩、构图、镜头、灯光、背景、道具、画面文字和商业风险，并生成中英文、Qwen-Image、FLUX、Midjourney 与负面提示词；
- 所有提示词默认可直接编辑和复制；具体品牌、Logo 与文案会被拆出并用变量替代，镜头参数明确标注为视觉推测；
- `0.13` 本地视觉服务：默认连接 `http://127.0.0.1:8080/v1` 的 Qwen3-VL OpenAI-compatible 服务，也可切换到云端兼容接口；设置页支持 `/models` 连通性检测；
- `0.14` 参考生成：通过兼容 `POST /images/edits` 的服务提供“只取风格 / 保持构图 / 保持商品”三种策略；“保持商品”必须先确认拥有图片和商品素材使用权；
- 视觉拆解历史只保存结构化文本和提示词，不保存源图；从历史打开时仍可查看、修改和复制，重新生成则需再次提供图片；
- `0.14.1` 设置体验修复：视觉服务改为“检测并保存”，检测成功即安全持久化地址、模型与 Key；设置页始终显示保存状态和“保存全部设置”，连接失败与等待视觉模型也会给出明确提示；
- `0.14.2` 新视觉任务会立即清空上一张图的拆解、提示词、风险和生成结果；分析期间锁定提示词页，并通过任务 ID 丢弃上一请求迟到的进度或结果，避免新旧图片内容串台；
- `0.14.3` 明确区分“提示词模板”和“实际生图模型”：参考生成卡片与加载状态直接显示设置中的模型；复制当前提示词提升为编辑器右上角高对比度操作；重新生成时清除旧完成状态并隐藏复制/保存按钮，完成后才恢复；
- `0.14.4` 将视觉设置中的“当前保存模型”和服务 `/models` 返回目录分层展示；目录不含当前名称时明确标注配置仍已保存、但尚未由目录确认。视觉拆解窗口新增最大化/还原按钮，并支持双击标题栏切换；
- `0.14.5` 视觉模型处理期间不再禁用“生图提示词”标签；用户可以提前进入独立等待页查看当前阶段，模型完成后提示词会在当前页面原地自动出现，失败时也会提供明确说明和返回入口；

## 本地视觉模型

Luvoelle 不捆绑数 GB 的模型权重。准备 Qwen3-VL 的 GGUF 与 mmproj 文件后，可通过支持多模态 OpenAI-compatible 接口的推理服务启动，例如：

```powershell
llama-server -m <model.gguf> --mmproj <mmproj.gguf> --port 8080
```

随后在“设置 → 视觉模型”中填写接口地址和实际模型名称，并点击“检测并保存”。也可连接 vLLM、LM Studio 或自建兼容服务。

## 隐私边界

- OCR 默认在独立线程中通过 PP-OCRv6 small 与原生 ONNX Runtime 完成；Tesseract 仅作离线兼容回退；
- 截图默认不写入历史记录；
- 翻译历史仅保存原文、译文、时间和 Provider 元数据；视觉历史保存结构化分析与提示词，不保存源图；
- API Key 通过 Electron `safeStorage` 调用 Windows 系统加密能力或 macOS 钥匙串保存；
- 使用在线翻译时，识别后的文字会发送给所选翻译服务，图片不会发送；
- 只有主动选择“截图转提示词”时，图片才会发送给已配置的视觉模型；使用本地端点时图片保持在本机；
- 只有主动点击“生成参考图”或“生成电商九宫格”时，图片和当前编辑后的提示词才会发送给已配置的图像生成服务；
- 屏幕冻结图仅用于本次框选；截取的区域会写入系统剪贴板，但不会默认保存为文件；
- Google 公共端点适合开箱体验，长期或商业使用建议切换到自有 OpenAI 兼容服务。

## 技术结构

```text
全局快捷键 / 托盘
        ↓
多显示器截图蒙层 → 图片导入 / 剪贴板
        ↓
        ├→ 本地 PP-OCRv6 / Tesseract 回退 → Provider 翻译 → 结果浮窗
        └→ Qwen3-VL / 兼容视觉服务 → 结构化提示词窗口
                                      ↓
                         参考生成服务（/images/edits）
        ↓
工作台 + 仅文本本地历史
```

桌面运行时采用 Electron；渲染层为原生 HTML、CSS 与 JavaScript，不依赖前端框架。主进程和渲染进程通过受限的 preload API 通信，启用 `contextIsolation`、关闭 `nodeIntegration` 并开启渲染沙箱。

## 视觉原则

界面吸收了 Apple 官网的设计方法，而非复制其品牌资产：

- 使用中性灰白背景和近黑主文字建立安静基底；
- 只把高饱和蓝用于主要操作与系统状态；
- 通过大字号标题、短说明和大面积留白建立阅读层级；
- 用 22–25px 大圆角卡片容纳独立任务；
- 导航、浮窗使用半透明模糊材质；
- 交互时长集中在 180–320ms，并支持 `prefers-reduced-motion`；
- 结果优先渐进出现：先截图反馈，再原文，最后译文。
