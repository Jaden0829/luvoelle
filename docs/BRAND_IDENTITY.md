# Luvoelle Folded L 品牌标记

本文件与其中描述的 Luvoelle 名称、Folded L 标记及生成资产公开可见，但不随软件源码许可授予商标或商业使用权。个人非商业构建及合理评论之外的使用必须遵守仓库根目录的 `TRADEMARKS.md` 与 `ASSETS_LICENSE.md`；对外分发的 Fork 必须更名并替换品牌资产。

## 核心概念

Luvoelle 的主标记为 **Folded L**。宽体字母 L 直接建立名称记忆；底部唯一的朱红折面代表截图中的画面被翻折、提取并转化为可以阅读、修改、翻译或继续生成的信息。

标记只保留三个清晰色块：深紫红底、瓷白 L、朱红折面。大尺寸时能看见纸张折叠关系，小到 16px 时仍能识别 L 的主体轮廓和红色记忆点。

## 色彩

- Deep Aubergine：`#260430` → `#33083E` → `#42104B`
- Porcelain：`#FBF8F0`
- Vermilion Fold：`#FF3B20`

## 使用规则

- 唯一母版是 `assets/icon.svg`；PNG、ICO 和应用内品牌标记均从该文件生成或加载。
- 不改变 L 的宽度、顶部左圆角、底部右圆角和朱红折面的三角比例。
- 不在标记内部增加截图框、星光、眼睛、相机、文字或功能角标。
- 标记周围至少保留其宽度 12% 的净空；小于 24px 时不叠加任何状态标识。
- 单色环境中保留完整 L 轮廓，折面可使用背景色形成负形；不要把折面删除后单独使用普通 L。

## 资产生成

```powershell
npm run build:icons
```

该命令从 SVG 母版生成：

- `assets/icon.png`：512px 主图标；
- `assets/icon.ico`：包含 16、24、32、48、64、128、256px 图层；
- `work/brand/sizes/`：用于小尺寸视觉检查的 PNG。
